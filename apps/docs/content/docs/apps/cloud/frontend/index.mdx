# Cloud Frontend

This section holds long-lived frontend implementation notes for `apps/cloud-ui`.

Use `cloud/handoff` for ownership, backend boundaries, and rollout contracts.
Use `cloud/frontend` for browser-local UI behavior, persistence expectations, and page-level frontend mechanics.

## Current Scope

- `frontend/i18n.mdx`: browser language behavior.
- `frontend/audio-engine.mdx`: playback, downloads, object URL, and local media lifecycle.
- `frontend/transcript-reading.mdx`: transcript display and reading interactions.
- `frontend/files-management.mdx`: browser-local file/library management surfaces.
- `frontend/settings.mdx`: settings, local maintenance, export/import, and credential UI boundaries.

Backend ownership, ASR relay behavior, runtime config, SQLite, and proxy contracts belong in `cloud/handoff`.
