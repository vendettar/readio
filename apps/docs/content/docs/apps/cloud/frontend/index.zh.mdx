# Cloud 前端

这个目录用于存放 `apps/cloud-ui` 的长期前端实现说明。

`cloud/handoff` 负责 ownership、后端边界与 rollout contract；
`cloud/frontend` 负责浏览器本地 UI 行为、持久化预期与页面级前端机制。

## 当前范围

- `frontend/i18n.zh.mdx`：浏览器语言行为。
- `frontend/audio-engine.zh.mdx`：播放、下载、object URL 与本地媒体生命周期。
- `frontend/transcript-reading.zh.mdx`：transcript 展示与阅读交互。
- `frontend/files-management.zh.mdx`：浏览器本地文件/library 管理界面。
- `frontend/settings.zh.mdx`：settings、本地维护、导入/导出与 credential UI 边界。

后端 ownership、ASR relay 行为、runtime config、SQLite 与 proxy contract 属于 `cloud/handoff`。
