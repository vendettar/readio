## 1. 范围

- 路由：`/settings`
- 主界面：`apps/cloud-ui/src/routeComponents/SettingsPage.tsx`

## 2. Cloud 当前职责

Settings 仍然负责：

- 语言切换
- 内容地区
- 浏览器本地维护动作
- 仍然存在的库导入/导出流程
- browser-local persistence 限制说明
- 当前 UI 暴露的用户自有 provider credential 输入与验证界面

## 3. Cloud 边界

Cloud Settings 文档必须体现当前 Cloud 所有权边界，不得把已明确删除的 legacy proxy 配置区块重新写回来。

## 4. Credentials 与导出边界

- Provider credentials 不是普通 settings。它们必须使用浏览器本地 credentials repository，或当前运行时契约定义的 transient in-memory values。
- Settings export/import 不得包含 provider credentials。
- 清除全部本地数据必须包含 credentials，并且必须防止 stale async writes 重新创建已清除的值。
- Runtime defaults 可以预填可见的 provider/model 选项，但不得静默持久化 API keys。
