# Technical Roadmap

This roadmap is final-state oriented. It tracks the current prototype baseline and near-term work only.

## Current baseline

- Active frontend: `apps/cloud-ui` with React, Vite, TanStack Router/Query, Zustand, Dexie, i18n, and tested UI flows.
- Active backend: `apps/cloud-api` with Go `net/http`, SQLite startup/migrations, discovery relay, ASR relay, media fallback, transcript asset metadata, and observability.
- Active docs: `apps/docs/content/docs`, especially the Cloud handoff and frontend contract pages.
- Active instruction set: `agent/instructions/cloud/basic`.

## Completed baseline contracts

- Cloud frontend/backend split with production-capable separate deployment.
- Backend-owned discovery routes for search, top charts, Editor's Picks, podcast lookup, and PodcastIndex episode list/detail.
- SQLite retained snapshot ownership for PodcastIndex episode page rendering.
- Browser-direct-first media with narrow backend pass-through fallback.
- Cloud ASR relay for provider transcription while keeping user credentials browser-supplied per request.
- Browser-safe runtime config allowlist.
- Application-owned observability, metrics, tracing, bounded log shipping, and protected admin summaries.

## Near-term maintenance priorities

1. Keep docs synchronized with code whenever discovery, ASR, media fallback, SQLite, runtime config, or browser-local persistence changes.
2. Continue reducing large frontend orchestration components without changing user-facing behavior.
3. Keep repository verification strict: build, lint, typecheck, unit tests, e2e coverage, Go tests, and docs consistency checks.
4. Keep public fallback and ASR surfaces abuse-resistant through validation, request bounds, rate limits, and structured logging.

## Future directions

- User accounts and server-backed sync.
- Multi-user SaaS deployment and auth.
- Native mobile app.
- Broader shared packages after the current frontend/backend boundaries stabilize.

Future items are not implemented until code, tests, and docs all agree.
